# Helper classes

All helper classes live in the `Espale.Utilities` namespace and are static, so you call them directly:

```csharp
using Espale.Utilities;
```

| Class | Description |
| --- | --- |
| [MathUtilities](math-utilities.md) | Means, ranges, remapping, vector helpers, directions, Bézier interpolation, angle clamping. |
| [RandomUtilities](random-utilities.md) | Random lerps, chance rolls, unit vectors, arrays, picking and shuffling. |
| [CollectionUtilities](collection-utilities.md) | Removing duplicates and picking a random item from any `IEnumerable`. |
| [ColorUtilities](color-utilities.md) | Extra named colors, brightening, darkening, grayscale and channel replacement. |
| [StringUtilities](string-utilities.md) | Word wrapping and scientific notation. |
| [AudioUtilities](audio-utilities.md) | Volume to decibel conversion and random clip picking. |
| [InputUtilities](input-utilities.md) | Detecting the connected gamepad and its platform. |
| [GizmoUtilities](gizmo-utilities.md) | Drawing arrows and crosses as gizmos. |
| [BetterDebug](better-debug.md) | Editor-only `Debug` wrappers. |
| [Constants](constants.md) | Pixel sizes, `1/√2`, gravity and frame delta times. |
