# Constants

| Constant | Value |
| --- | --- |
| `PIXEL_LENGTH_16PPU` | `0.0625`, the size of one pixel at 16 pixels per unit |
| `PIXEL_LENGTH_32PPU` | `0.03125`, the size of one pixel at 32 pixels per unit |
| `INVERSE_SQRT_OF_TWO` | `1 / √2` |
| `G` | `9.801`, gravity on Earth's surface |
| `DT_60FPS` | Delta time of one frame at 60 FPS |
| `DT_30FPS` | Delta time of one frame at 30 FPS |
