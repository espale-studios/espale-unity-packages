# Components

Add these from **Add Component** in the Inspector. Their namespaces are listed with each one in case you add them from code.

| Component | Description |
| --- | --- |
| [AnimationCurveRenderer](animation-curve-renderer.md) | Draws an `AnimationCurve` between two points with a `LineRenderer`. |
| [ObjectDetector](object-detector.md) | Fires events when a target enters or leaves a circle or rectangle. |
| [Light2DSpriteMatcher](light2d-sprite-matcher.md) | Keeps a sprite `Light2D` in sync with a `SpriteRenderer`. |
| [ArcCollider2D](arc-collider-2d.md) | Builds an arc-shaped `EdgeCollider2D`. |
| [AudioSourceRandomizer](audio-source-randomizer.md) | Randomizes an `AudioSource`'s clip, volume and pitch. |
| [SpriteRendererRandomizer](sprite-renderer-randomizer.md) | Randomizes a `SpriteRenderer`'s sprite and color. |
