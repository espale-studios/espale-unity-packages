# SpriteRendererRandomizer

<xref:Espale.Utilities.Components.Randomizers.SpriteRendererRandomizer> (`Espale.Utilities.Components.Randomizers`) gives a `SpriteRenderer` a random sprite and color, which is useful for props like grass, rocks or debris.

| Field | Description |
| --- | --- |
| **Randomize On Start** | Randomize once in `Start`. |
| **Randomize Sprite**, **Sprite Options** | Pick a random sprite from the list. |
| **Randomize Color**, **Color Range** | Pick a random color from the gradient. |

Call `Randomize()` to pick new values at any time.
