# KeyBrowser

**Espale Studios > Localization > Key Browser** lists every key.

- **Search** filters keys by name.
- The dropdown under the search bar filters by status: **All**, **Localized** or **Not Localized**.
- Next to each key, every language's code is shown in green if it has a value for that key, or red if it's missing.
- The built-in keys `lng_name` and `lng_error` are shown in bold italics.
- Click a key to open it in the **Key Editor**.
- **Refresh** reloads the files, for example after you pull changes or run the CSV scripts.
