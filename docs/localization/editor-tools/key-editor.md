# KeyEditor

**Espale Studios > Localization > Key Editor** edits one key at a time.

1. Type a key name in the field at the top. Names are converted to key format as you type (lower case, spaces become underscores).
2. If the key exists, a text field appears for each language. A language label turns red while its value has unsaved changes.
3. **Update Values** saves the values.
4. **Rename Key** renames the key to the name in the field next to it.
5. **Remove Key** deletes the key and its values in every language.

If the key doesn't exist yet, select **Add New Key** to create it.
