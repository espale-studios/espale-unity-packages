# Editor tools

All windows are under **Espale Studios > Localization** in the menu bar. They read and write the files in `Assets/Localization/Resources/` directly, so changes show up in version control right away.

| Tool | Description |
| --- | --- |
| [KeyBrowser](key-browser.md) | Lists and searches every key and shows which languages are missing values. |
| [KeyEditor](key-editor.md) | Adds, edits, renames and removes one key. |
| [LanguageManager](language-manager.md) | Adds, removes and previews languages. |
| [LocalizedKeyAttribute](localized-key-attribute.md) | Turns a `string` field into a key picker in the Inspector. |
