# Sub graphs

Sub graphs are reusable groups of nodes. Add one to your own Shader Graph from the **Create Node** menu by searching for its name. They live in `Runtime/Sub Shaders`.

| Sub graph | Description |
| --- | --- |
| [Glitch](glitch.md) | Samples a texture with an animated glitch. |
| [Pixelate](pixelate.md) | Snaps a UV to a texture's pixel grid. |
| [Pixelated UV](pixelated-uv.md) | The mesh UV, snapped to the pixel grid. |
| [Pixelated Screen Pos](pixelated-screen-pos.md) | The screen position, snapped to the pixel grid. |
