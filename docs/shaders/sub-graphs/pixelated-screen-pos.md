# Pixelated Screen Pos

**Category:** Espale/PixelArt

The screen position passed through [Pixelate](pixelate.md). Useful for screen-space effects that should stay pixel-aligned.

| Input | Type | Description |
| --- | --- | --- |
| Texture | Texture 2D | The texture whose pixel size sets the grid. |

| Output | Type | Description |
| --- | --- | --- |
| New | Vector 4 | The snapped screen position. |
