# Pixelate

**Category:** Espale/PixelArt

Snaps a UV to the pixel grid of a texture by rounding it to the nearest texel. Use it to keep effects on whole pixels in pixel art.

| Input | Type | Description |
| --- | --- | --- |
| UV | Vector 4 | The UV to snap. |
| Main Texture | Texture 2D | The texture whose pixel size sets the grid. |

| Output | Type | Description |
| --- | --- | --- |
| New | Vector 4 | The snapped UV. |
