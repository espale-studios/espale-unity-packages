# VersionDisplayer

<xref:Espale.UI.VersionDisplayer> shows the game's version (`Application.version`, set in **Project Settings > Player > Version**) on a colored background, which helps tell builds apart in screenshots and bug reports.

| Field | Description |
| --- | --- |
| **Toggle Key** | Key that shows and hides the label. None by default. |
| **Active On Start** | Show the label when the game starts. |
| **Bg Color** | Background color. Red by default. |
| **Prefix Key** | Optional [localization key](../../localization/index.md) for text shown before the version, such as "Version" or "Early Access". |

The label updates when the language changes.
