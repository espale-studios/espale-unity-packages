# UI sounds

Components for adding sound to menus. The **Button**, **Toggle** and **Multi Select Dropdown** prefabs already include them.

| Type | Description |
| --- | --- |
| [SelectableAudioSource](selectable-audio-source.md) | Plays sounds when a `Selectable` is highlighted, selected or pressed. |
| [UIAudioManager](ui-audio-manager.md) | Plays a one-shot clip on a temporary `AudioSource`. |
