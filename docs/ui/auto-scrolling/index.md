# Auto scrolling

With a mouse, players scroll a list themselves. With a gamepad or keyboard they move the selection, and the list should follow. These two components do that.

| Component | Description |
| --- | --- |
| [ScrollViewAutoScroller](scroll-view-auto-scroller.md) | Scrolls a `ScrollRect` to follow the selected item. |
| [DropdownAutoScroller](dropdown-auto-scroller.md) | Does the same for an open `TMP_Dropdown` list. |
