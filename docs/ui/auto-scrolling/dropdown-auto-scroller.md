# DropdownAutoScroller

Add <xref:Espale.UI.DropdownAutoScroller> to a `TMP_Dropdown`. It adds a Scroll View Auto Scroller to the dropdown's list so the list follows the selection while it's open.

| Field | Description |
| --- | --- |
| **Is Active** | Follow the selection while the list is open. |
| **Always Auto Scroll On Expand** | Even when **Is Active** is off, jump to the current value when the list opens. |
| **Use Unscaled Time** | Keep scrolling while `Time.timeScale` is 0. |
| **Auto Scroll Speed** | How fast the list scrolls (1 to 100). |
