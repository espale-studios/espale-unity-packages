# Widgets

Create each widget from **Espale Studios > UI > Widgets** or **GameObject > Espale UI > Widgets**. The prefabs come with their child objects already set up, so it's easiest to start from them rather than adding the components by hand.

| Widget | Description |
| --- | --- |
| [Toggle](toggle.md) | An on/off control with an animated fill. |
| [ProgressBar](progress-bar.md) | A linear or radial bar that animates toward a value. |
| [MultiSelectDropdown](multi-select-dropdown.md) | A dropdown where several options can be ticked. |
| [InputVisualizer](input-visualizer.md) | Shows the right gamepad button prompt for the player's controller. |
